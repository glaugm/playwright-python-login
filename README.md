# Playwright Python Login Tests

Automated end-to-end login tests using Playwright with Python and pytest.

## About

This project automates login scenarios on a web application to practice browser automation, element locators, assertions, and test execution with pytest.

## Technologies

- Python 3.13
- Playwright
- pytest
- Git and GitHub

## Test Scenarios

| Test | Description |
|---|---|
| Invalid password | Verifies that an error message appears when the user enters an incorrect password. |
| Successful login | Verifies that valid credentials redirect the user to the dashboard and display a welcome message. |

## Prerequisites

- Python 3.13 or a compatible Python version
- Git
